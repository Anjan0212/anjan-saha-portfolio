## Contact form restrictions

- Name: letters and spaces only.
- Email: valid email format.
- Phone: digits only, maximum 10 digits.
- Subject: required.
- Message: minimum 10 characters.

The form validates in the browser and opens the user's mail client using a `mailto:` action. No backend is claimed or required.
